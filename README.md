# ম্যাংগো গার্ডেন (Mango Garden) — খাঁটি খেজুরের গুড়

React + Vite দিয়ে তৈরি ল্যান্ডিং পেজ, অর্ডার সিস্টেম এবং অ্যাডমিন ড্যাশবোর্ড।

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
```

- দাম ও প্যাকেজ তালিকা: `src/data.js`
- কালার প্যালেট ও স্টাইল: `src/index.css`
- ছবি: `public/img/`
- অর্ডার ডাটাবেস ও অ্যাডমিন প্যানেল: Supabase (`#admin`)
